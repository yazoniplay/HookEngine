# HookEngine\n\nChrome Manifest V3 side-panel extension that turns YouTube transcripts and article text into an X thread, LinkedIn post, and TikTok hooks using **Gemini 3.5 Flash-Lite**.\n\n## Architecture\n- Chrome extension UI and page extraction\n- No user accounts or sign-in required; the extension calls the Edge Function with a public key\n- Supabase Edge Function: `hookengine-generate` calls Gemini server-side\n- Gemini API key is stored as a Supabase Edge Function secret and is never shipped in the extension\n\n## Supabase setup\nThe extension is configured for the **Yazoniplay Next** Supabase project.\n- Project URL: `https://ppaknwuwiublxogclqdw.supabase.co`\n- Edge Function: `https://ppaknwuwiublxogclqdw.supabase.co/functions/v1/hookengine-generate`\n\nBefore generation can work, open Supabase Dashboard → Edge Functions → Secrets and add:\n- `GEMINI_API_KEY`: your Google AI Studio API key\n- `GEMINI_MODEL`: `gemini-3.5-flash-lite` (optional; this is the default)\n\nNever commit the Gemini API key or put it in extension files. The extension does not require Supabase Auth accounts. The public publishable key is used only to call the Edge Function; keep the Gemini API key in Edge Function secrets.\n\n## Load the extension\n1. Open `chrome://extensions` in Chrome.\n2. Enable Developer mode and choose **Load unpacked**.\n3. Select the HookEngine repository folder.\n4. Open HookEngine, then paste source text or extract a page.\n5. Click **Generate content**.\n\n## YouTube transcript limitations\nYouTube changes its DOM often. Open the video's own **Show transcript** panel before clicking **Read current tab**. The extension extracts captions already rendered in the page; it does not bypass access controls or fetch private captions.\n\n## API\n- `POST /functions/v1/hookengine-generate`\n- Uses the Supabase publishable key in the `apikey` and `Authorization` headers; no user session required\n- Request: `{ "text": "...", "title": "...", "sourceUrl": "..." }`\n- Response: `{ "x_thread": "...", "linkedin_post": "...", "tiktok_hooks": "..." }`\n\nThe Edge Function is deployed with JWT verification enabled. Add rate limiting and usage/credit accounting before exposing the app publicly at scale.\n
